## 中文

PulseDesk（下称"本应用"）尊重并保护用户隐私。

### 我们收集什么

**不收集。** 本应用不收集、不存储、不上传任何个人身份信息（PII）。

本应用显示的所有数据——网速、CPU 使用率、内存、温度、硬件信息、进程列表——**全部在本机采集、本机处理、本机显示**，不会发送到任何服务器。

本应用在以下情况会产生网络访问：

1. **授权校验**（仅完整版）：向授权服务器验证许可证有效性。此过程只传输许可证密钥和机器码哈希，不包含任何个人身份信息。

除此之外，本应用不与任何服务器通信。

本应用为读取系统监控数据，以 `runFullTrust` 模式运行（这是 Windows 桌面应用的标准打包方式），需要访问：

- 系统性能计数器（CPU / 内存 / 网络 / 温度）
- 进程列表
- 硬件信息（WMI）

这些访问仅用于本机界面显示，无任何上传行为。

## English

PulseDesk ("the App") respects and protects user privacy.

### What We Collect

**Nothing.** The App does not collect, store, or transmit any personally identifiable information (PII).

All data shown in the App — network speed, CPU usage, memory, temperature, hardware info, process list — is collected, processed, and displayed **entirely on your local machine**. Nothing is sent to any server.

### Network Communication

The App makes network requests only in these cases:

1. **License verification** (full version only): validates the license with a license server. Only the license key and a machine-code hash are transmitted — no personal information.
2. **Update check** (can be disabled): contacts GitHub Releases for new version numbers.

Otherwise, the App does not communicate with any server.

### Permissions

To read system monitoring data, the App runs in `runFullTrust` mode (standard for Windows desktop apps packaged as MSIX) and accesses:

- System performance counters (CPU / memory / network / temperature)
- Process list
- Hardware information (WMI)

All of this is used solely for on-screen display on your machine. Nothing is uploaded.

### Children

The App is not directed at children under 13 and collects no user data.
